## 5. 현재 남은 핵심 작업

사람 검수 전 자동 산출물은 대부분 준비되어 있습니다. 최종 논문 claim을 위해 남은 작업은 다음입니다.

| 항목 | 현재 상태 | 필요 작업 |
| --- | --- | --- |
| Human-gold annotation | 0/10 reviewed files | annotator A/B 5개 batch 반환 |
| Adjudication | edited file 없음 | `adjudication_edited.jsonl` 작성 |
| IAA | 미계산 | annotator A/B 반환 후 계산 |
| Proposed human-gold scoring | 미완료 | adjudicated gold 이후 평가 재실행 |
| Mapping expert review | reviewed file 없음 | top-20 group 검수 반환 |
| NCS-PCF crosswalk expert review | reviewed file 없음 | Layer2 bridge 기반 crosswalk 후보 utility 검수 반환 |
| Active-review human effort | reviewed CSV 없음 | timing/correction CSV 반환 |

이 파일들이 반환되면 다음 refresh 명령으로 final table을 갱신합니다.

권장 경로는 preflight와 checksum 확인을 같이 수행하는 wrapper입니다.

```bash
PYTHON_BIN=/home/minjoo/tdpo2_aaai2027/.venv_tdpo2/bin/python \
LLM_PYTHON=/home/minjoo/tdpo2_aaai2027/.venv_tdpo2/bin/python \
APPLY_IMPORTS=1 \
bash scripts/run_cape_human_return_apply.sh
```

저수준 refresh만 직접 실행해야 하는 디버깅 상황에서는 `scripts/run_cape_post_annotation_refresh.sh`를 사용합니다.
