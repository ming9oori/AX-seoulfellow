## 3. Gold Evidence

- 원문 기반 질문은 `evidence_text`, page, section metadata를 이용해 현재 Neo4j snapshot의
  `EvidenceSpan` ID에 다시 정렬한다.
- 합성 질문은 미리 선언한 parent 문항의 동결 Gold Evidence 합집합을 상속한다.
- 전체 210문항 중 207개, 주 비교 178문항 중 175개에 평가 가능한 Gold Evidence가 있다.
- TaskFrame·PCF Gold는 독립 전문가 label이 아니라 Evidence에서 현재 그래프를 거슬러 올라가
  계산한 내부 일관성용 값이다.

검색 지표는 질문별 Gold 집합과 Top-k 검색 결과를 비교한다.

```text
Hit@1       = 1위가 Gold이면 1, 아니면 0
Hit@5       = Top-5에 Gold가 하나라도 있으면 1
Recall@5    = Top-5에서 찾은 Gold 수 / 전체 Gold 수
Complete@5  = 모든 Gold가 Top-5에 있으면 1
MRR         = 처음 발견된 Gold 순위의 역수
```

```text

├─ 원문 기반 150
│  ├─ 입찰과 제안 53
```
