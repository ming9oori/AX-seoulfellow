3. 질문에서 Aspect를 만드는 방법

  1. Kiwi 형태소 분석: 질문을 ‘기회 분석 / 끝나 / 뒤 / 제안 참여 / 의사 결정 / 전 / 이루어지’처럼 정규화합니다.
  2. 후보 구 생성: 업무 대상, 행동, 시간·조건을 나타내는 연속 구절을 후보로 만듭니다.
  3. 그래프 grounding: 후보를 질문, PCF, TaskFrame, EvidenceSpan 및 실제 경로와 비교합니다.
  4. 상위 관점 선택: 다섯 신호의 순위를 동일 가중으로 결합하고 역할이 겹치지 않는 3개 관점을 선택합니다.

이 과정에는 정답, Gold Evidence ID, LLM 학습이 사용되지 않습니다.
